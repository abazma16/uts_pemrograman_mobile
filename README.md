# Aplikasi Daftar Pengguna API (UTS Pemrograman Mobile)

Aplikasi mobile berbasis Flutter yang mengambil dan menyajikan data pengguna secara dinamis dari REST API.

## Fitur Utama
- Menampilkan daftar pengguna (foto avatar, nama lengkap, dan email) dari REST API.
- Menggunakan `FutureBuilder` untuk menangani status asinkron: Loading, Success, dan Error.

## Package yang Digunakan
- `http`: Untuk menangani HTTP Request ke REST API.

## Cara Menjalankan Aplikasi
1. Clone repositori ini.
2. Jalankan `flutter pub get` di terminal.
3. Jalankan aplikasi menggunakan `flutter run`.
